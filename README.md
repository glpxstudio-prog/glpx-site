# GLPX Studio website

Static site: plain HTML + CSS, no build tools needed to host. Free on GitHub Pages.

Pages
- `index.html` — homepage (overview, selected work, services, pricing, about teaser)
- `branding.html` — branding packages, crop guide, gallery, FAQ
- `headshots.html` — headshot gallery, session steps, what to wear, quote CTA
- `editorial.html` — editorial / music / beauty gallery, session rates, add-ons
- `about.html` — Gerson's story, behind-the-scenes, how I work
- `contact.html` — booking, contact details, call prep, booking FAQ

Shared
- `assets/style.css` — base layout styles
- `assets/v2.css` — homepage design (red #E53935 / black #100D0C / bone; Libre Caslon Condensed + Archivo + DM Sans)
- `assets/inner.css` — puts every inside page in the homepage style, plus mobile centering
- `assets/site.js` — click-to-enlarge gallery lightbox
- `assets/img/` — web-sized photos (max 1400px)
- `build.py` — regenerates the pages with the shared header/footer. Edit the page text in it, then run `python3 build.py`.

Every "Book" button points to the GHL booking widget.

Local area pages (SEO)
- 64 pages: {branding-photography, headshots, editorial-photography, corporate-event-photography}-{area}.html for 16 areas
- `areas.html` — hub linking every area and service
- `sitemap.xml` + `robots.txt` — submit the sitemap in Google Search Console after launch
- `areas.py` — area copy and generator. Edit area text there, then run `python3 areas.py` (it re-runs build.py too)

Homepage
- `index.html` — live homepage (editorial red/black design), generated by `v2.py` with styles in `assets/v2.css`
- `index-v1.html` — previous red homepage, kept as a backup
- Run `python3 areas.py` to rebuild everything (pages, area pages, homepage)

Final pass
- `finish.py` runs at the end of `areas.py`: adds business structured data, social share previews (og:image), favicon and lazy-loading images to every page
- `404.html` — "page not found" page for GitHub Pages

## Launch day (do these in order, same day)

Your domain is registered with **GoDaddy** (nameservers ns77/ns78.domaincontrol.com). Right now `www.glpxstudio.com` points to Pixpa (`domains.pixpa.com`).

**1. GitHub (before touching the domain)**
- Create a free GitHub account and a **public** repository named `glpx-site`.
- Upload everything in this folder (skip `__pycache__`, `_blog_src` is fine to include or skip).
- Settings → Pages → Deploy from a branch → `main` / root → Save.
- Check the site at `https://YOUR-USERNAME.github.io/glpx-site/` before going further.

**2. GoDaddy DNS** (My Products → glpxstudio.com → DNS)
- `www` CNAME: change `domains.pixpa.com` → `YOUR-USERNAME.github.io`
- `@` A records: replace with `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
- Add `gallery` CNAME → `domains.pixpa.com` (keeps client galleries on Pixpa)

**3. GitHub custom domain**
- Settings → Pages → Custom domain: `www.glpxstudio.com` → Save. When the check passes, tick **Enforce HTTPS**.

**4. Pixpa** (studio.pixpa.com → Settings → Domain Name)
- Disconnect `www.glpxstudio.com`, then connect `gallery.glpxstudio.com`.
- Client albums will then live at `gallery.glpxstudio.com`. The Client Gallery button already points there.
- Keep your Pixpa plan active for client galleries.

**5. Google**
- Search Console: add `https://www.glpxstudio.com`, submit `sitemap.xml`.
- Google Business Profile: confirm the website link is `https://www.glpxstudio.com`.
- For the next 2 to 4 weeks, check Search Console → Pages for any "Not found (404)" and add a redirect folder for it in `blog.py` (REDIRECTS).
